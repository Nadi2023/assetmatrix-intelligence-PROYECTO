# AssetMatrix Intelligence

API REST para el monitoreo de activos bursátiles y criptográficos, construida con Node.js, Express y MongoDB.

## Cómo correr el proyecto
1. Clonar el repositorio.
2. Crear un archivo `.env` basado en `.env.example`.
3. Levantar con Docker: `docker-compose -f docker-compose.local.yml up --build`

## Stack
- Node.js 20+ / Express.js
- MongoDB + Mongoose
- Swagger (OpenAPI 3.0)
- Jest + Supertest (TDD)
